## macOS 0.6.32

本轮按 owner 的 macOS 优先发行授权发布，Windows 新版延后。0.6.32 的 App 与最终 DMG 均已通过 Developer ID 签名、Apple 公证、staple 和 Gatekeeper 检查。Universal 安装包包含 Apple Silicon 与 Intel 架构。

新增基准简历右侧 AI 修改助手、可编辑修改稿保存、历史版本和撤销；支持保留结构扩充或 Skills 前置并整合经历。简历工作台统一岗位定制、求职信、执行流程、预览、版式和导出，窄窗口支持横向选择入口。

当前公开正式版与安装包以 [Latest Release](https://github.com/JobHunter-AI/jobhunter-releases/releases/latest) 和签名更新清单为准。下载页按平台显示实际版本，更新保留本地资料。

## 历史 0.6.7 Mac 预发布（正式标记已撤回）

Universal 安装包支持 Apple Silicon 与 Intel，已完成 Developer ID 签名、Apple 公证及 Gatekeeper 检查。包含匠人官方模型、统一会员额度、AI 对话创建简历、内置 Codex 和 AI 稳定性修复。

App 在启动、恢复登录和开始任务之前检查签名更新，安装成功后自动重启。设置页也可手动检查。更新保留本地资料；免费基础交流额度用完即停止，不自动切换付费档。

0.6.7 曾因当时的双平台统一发布规则恢复为 Pre-release。历史安装包与记录保留，不覆写旧版本。2026-10-14 的 macOS 优先发行授权适用于本轮 0.6.32。

## AI 与资料

本地资料保存在用户电脑。使用匠人官方模型时，请求所需内容会经匠人服务发送给配置的模型供应商；使用个人 Claude/Codex 时走对应账号。免费档只提供有限基础交流，完整简历任务需要相应权益。不要把账号凭据或不希望发送给模型的信息放进对话。

## 产品截图

官网 `assets/` 包含正式 Logo 和实际桌面 UI 截图。2026-10-15 新拍 8 张，功能导览用 10 个场景串联资料库、经历编辑、岗位分析、定制、AI 修改、版本、模板导出、求职信、进程与面试安排。截图由同版本产品的隔离原生窗口拍摄，使用 App 自带匿名 Demo；没有公开真人简历、联系方式或用户文件。演示稿不冒称通过真实模型审核，执行进度仍显示实际状态。

手机页面支持截图标签横滑与放大预览，尊重系统减少动态效果设置。

## 功能导览维护

`?screen=templates#screens` 可直达任意功能；切换后刷新和浏览器前后退保留选择。播放由访客主动开启，每页 6 秒，播完停止；手动切换、打开大图、页面隐藏或导览离开视口时停止。系统减少动态效果设置会关闭光点与过渡动画。

图片来源记录见 `assets/screenshots-provenance.json`。光点为网页叠加的操作位置提示，截图不代表实时 AI 执行或速度。新图片从 0.6.32 隔离 Demo 窗口拍摄，没有模型请求，不包含个人资料。
